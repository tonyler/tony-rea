UI / UX Rules

Design:
- Artistic, elegant, minimal
- Clean colors
- Large whitespace
- Typography-forward
- No neon
- No heavy borders
- Calm, professional feel

Assistant Tab:
- Mode toggle (Mod / Education)
- Input box
- Optional context box
- Output area
- Copy button (Mod mode)
- Sources displayed separately (not copied)

Feed Tab:
- Project selector
- Create project
- Feed content area
- Update / replace / deprecate flows
- Confirmation dialogs for destructive actions

Threads Tab:
- Input content
- Thread length selector
- Output posts as separate blocks
- Character counter per post
- Copy buttons per post
