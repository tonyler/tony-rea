Feed Ingest Rules

Extract ONLY:
- Stable facts
- Definitions
- Numbers
- Dates
- Policies
- Procedures

Exclude:
- Hype
- Opinions
- Emojis
- Community chatter
- Marketing fluff

Sources:
- Preserve exact URLs
- If none provided, add verification_note
- Never invent links

Conflicts:
- Flag conflicting data
- Prefer newer info
- Never silently overwrite
